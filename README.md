Data Analytics Internship – Week 3 project focused on data visualization and reporting using Python, Pandas, Matplotlib, and Seaborn. Includes bar charts, line charts, scatter plots, heatmaps, data insights, and business recommendations using the Online Retail dataset.


# YuvaIntern Week 3 – Data Visualization and Reporting

## 📌 Project Overview
This project is part of my Data Analytics Internship at YuvaIntern. The objective is to analyze the Online Retail dataset and create meaningful visualizations to identify sales trends, product performance, and relationships between business variables.

## 🎯 Objectives
- Explore and visualize retail sales data.
- Identify monthly revenue trends.
- Analyze top-performing products.
- Understand the relationship between quantity, unit price, and revenue.
- Communicate business insights through charts and a detailed report.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Word

## 📊 Visualizations
1. **Bar Chart:** Compares revenue across the top 10 products.
2. **Line Chart:** Shows monthly revenue trends over time.
3. **Scatter Plot:** Examines the relationship between quantity sold and revenue.
4. **Correlation Heatmap:** Shows correlations among quantity, unit price, and revenue.

## 🔍 Key Analysis
- Monthly revenue patterns and fluctuations.
- Products contributing the most revenue.
- Relationships between sales quantity, unit price, and revenue.
- Potential business opportunities based on the observed trends.

## 📈 Business Value
The analysis helps demonstrate how data visualization can support retail sales monitoring, product performance analysis, and data-driven business decisions.

## ▶️ How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries:
   ```bash
   python -m pip install pandas matplotlib seaborn openpyxl
   ```
3. Open `Week3_Data_Visualization.ipynb` in Jupyter Notebook.
4. Update the dataset path if necessary.
5. Run the notebook cells in order to generate the visualizations and outputs.

## 📁 Dataset
The project uses the **Online Retail** dataset. Place the Excel dataset in the appropriate folder and update the notebook's file path if needed.
